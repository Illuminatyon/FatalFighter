# FatalFighter 🥊

Un jeu de combat type Street Fighter entièrement codé en Python pur, sans aucune bibliothèque de jeu vidéo.

## 🎮 À propos du projet

FatalFighter est un projet scolaire de Terminale réalisé par une équipe de 4 personnes. C'est un jeu de combat 1v1 inspiré du genre Street Fighter, développé uniquement avec Python, ce qui a été le plus grand défi du projet.

### Ce qui a rendu le projet challenge

- ✅ Projet réalisé uniquement en Python
- ✅ Aucune bibliothèque de jeu vidéo utilisée
- ✅ Développement complet en autonomie
- ✅ Temps de réalisation limité à 4 semaines
- ✅ Travail effectué avec le Bac à côté

## 🚀 Lancement rapide

1. Clonez le projet :
   ```bash
   git clone https://github.com/Illuminatyon/FatalFighter.git
   cd FatalFighter
   ```

2. Lancez le jeu :
   ```bash
   FatalFighter.exe
   ```

## 📌 Objectif du projet

Créer un jeu de combat fun et jouable, avec une ambiance inspirée des jeux de baston classiques, en restant dans un cadre technique exigeant : coder tout en Python, sans moteur ni bibliothèque dédiée.
